# Коммерческий сайт для подбора кандидатов на контрактную службу

Портфолио-кейс коммерческого проекта: информационный сайт о направлениях контрактной службы, вакансиях, условиях оформления и сборе заявок от кандидатов. Проект был реализован под ключ примерно за 3 дня: от уточнения требований и правок с заказчиком до верстки, интеграций, размещения на хостинге и последующей доработки после запуска.

Сайт построен как легкий статический frontend с небольшим PHP-обработчиком заявок на стороне хостинга. Основной сценарий пользователя: изучить условия и вакансии, выбрать направление, оставить заявку или заказать обратный звонок.

## Стек

- HTML5, CSS3, vanilla JavaScript
- PHP для серверной обработки форм
- Google Apps Script для записи заявок в Google Таблицу
- Яндекс.Метрика и Top.Mail.Ru / VK Pixel
- FTP-хостинг, домен, `robots.txt`, `sitemap.xml`

## Интеграции

Реализованные интеграции подтверждаются кодом в `api/`, `integrations/`, HTML и JavaScript.

- **PHP-обработчик заявок**: `api/send-lead.php` принимает JSON из форм, валидирует обязательные поля, очищает данные, рассчитывает возраст по дате рождения и возвращает JSON-ответ.
- **Email-уведомления**: обработчик формирует текстовую и HTML-версию письма и отправляет заявку через стандартную функцию `mail()` на стороне хостинга.
- **Google Таблица**: обработчик дополнительно отправляет данные заявки в Google Apps Script webhook; скрипт из `integrations/google-apps-script.gs` добавляет строку в таблицу.
- **Яндекс.Метрика**: счетчик подключен на страницах сайта, в JavaScript отправляются цели для кликов по заявке, открытия обратного звонка, начала заполнения форм и успешной отправки.
- **Top.Mail.Ru / VK Pixel**: счетчик подключен на страницах сайта, в JavaScript отправляются события `reachGoal` для пользовательских действий.
- **SEO и предпросмотр ссылок**: настроены `robots.txt`, `sitemap.xml`, Open Graph и Twitter Card метатеги.

## Развертывание

Проект рассчитан на классический shared-хостинг с поддержкой PHP:

- статические страницы и ассеты размещаются в публичной директории сайта;
- `api/send-lead.php` должен быть доступен по относительному пути `api/send-lead.php`;
- для отправки писем на хостинге должна быть доступна PHP-функция `mail()`;
- для записи в Google Таблицу используется опубликованный Google Apps Script endpoint;
- аналитические счетчики подключены напрямую в HTML и через события в `assets/js/app.js`.

Репозиторий не использует сборщик, npm-зависимости или CMS. Это сознательно упрощает размещение и сопровождение проекта на обычном PHP-хостинге.

## Структура проекта

```text

├── api/                    # PHP-обработчик заявок
├── assets/
│   ├── css/                # стили сайта
│   ├── js/                 # интерактив, каталог вакансий, формы, аналитические цели
│   └── images/             # изображения, favicon, social preview, образец контракта
├── integrations/           # Google Apps Script для таблицы заявок

├── index.html              # главная страница
├── robots.txt
└── sitemap.xml
```

## Особенности проекта

- Проект был выполнен в сжатые сроки и дорабатывался по реальным комментариям заказчика.
- Вакансии и направления собраны в JavaScript-каталог, поэтому карточки и детальные страницы синхронизированы между собой.
- Заявка сохраняет контекст выбранной вакансии и передает его в обработчик, письмо и таблицу.
- Для аналитики фиксируются не только просмотры страниц, но и важные действия пользователя: интерес к заявке, начало заполнения и успешная отправка.
