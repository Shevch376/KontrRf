# Сайт о контрактной службе

Статический информационный сайт о направлениях контрактной службы, условиях оформления, вакансиях и заявке на обратную связь.

Проект сделан без сборщика: страницы открываются напрямую из HTML-файлов, стили и скрипты лежат в папке `assets`.

## Структура

- `index.html` — главная страница с основными блоками, вакансиями, FAQ и формой заявки.
- `pages/terms.html` — страница с условиями и этапами оформления.
- `pages/vacancies.html` — каталог вакансий по направлениям.
- `pages/vacancy.html` — детальная страница вакансии.
- `assets/css/styles.css` — основные стили сайта.
- `assets/js/app.js` — интерактив главной страницы, формы, модальные окна и карточки вакансий.
- `assets/js/vacancies.js` — данные и логика детальных страниц вакансий.
- `assets/images/` — изображения для карточек, разделов и страниц.

## Как открыть

Откройте `index.html` в браузере. Для проверки внутренних страниц используйте ссылки в навигации или файлы из папки `pages`.

## Текущее состояние

Сайт адаптирован под десктоп и мобильные экраны. В текущей версии доработаны визуальные блоки, карточки вакансий, футер, форма заявки и страницы с условиями.
